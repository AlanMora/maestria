# maestria

- `main.py`: filtros de webcam (detección de bordes y segmentación por k-means). Requiere `pip install -r requirements.txt`.
- `neural_network.py`: red neuronal en Python puro (MLP con perceptrones sigmoides y capas RBF).
- `mlp_app.py`: demo interactiva en tkinter. Agrega puntos por clase, entrena y evalúa la frontera de decisión: `python3 mlp_app.py` (requiere `python3-tk`).
